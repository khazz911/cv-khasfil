## 🌐 Bonus Nilai Tambah: Deploy ke GitHub Pages

Sesuai deskripsi tugas:
> *"Bonus (nilai tambah, tidak wajib): publish website ke GitHub Pages — sertakan link repository/demo jika ada."*

Langkah praktis untuk mempublikasikannya secara online:
1. Buat akun di [GitHub.com](https://github.com) (jika belum ada).
2. Buat repositori baru, misalnya dengan nama: `cv-khazz`.
3. Unggah file `index.html`, `style.css`, `foto-profil.jpg`, `README.md`, dan folder `assets/` ke repositori tersebut.
4. Buka menu **Settings** > **Pages** pada repositori GitHub Anda.
5. Pada bagian **Branch**, pilih `main` dan folder `/ (root)`, lalu klik **Save**.
6. Dalam 1-2 menit, website Anda sudah aktif secara online di alamat:
   `https://<username-kamu>.github.io/cv-khazz/`
7. Salin link tersebut dan lampirkan di Edlink untuk mendapatkan nilai maksimal!
